Sincronizador Excel — hojas JULIO y VALORES

Sube el Excel maestro (VARIABLES) y luego los archivos nuevos. El sistema inserta los datos de las hojas JULIO y VALORES en el maestro, marca cada fila insertada con estado LEÍDO y lleva un registro para no volver a leer lo mismo. Nada se guarda en el servidor: al recargar, se pide subir todo de nuevo.

1 Excel maestro (VARIABLES … .xlsm / .xlsx)

Es el archivo donde se insertan los datos. Debe tener las hojas JULIO y VALORES.

2 Archivos nuevos con hojas JULIO / VALORES

Puedes subir uno o varios. Solo se leen las hojas cuyo título sea JULIO o VALORES.

3 Descargar maestro actualizado

Con los datos insertados, el estado LEÍDO y el registro de control.

Todo se procesa en tu navegador — sin base de datos, sin Supabase, sin subir nada a un servidor.
El registro de lecturas queda dentro del propio Excel (hoja CONTROL_LECTURAS).
